# Troubleshooting

| Symptom (tool result)                                                | Meaning                                                                                                                                                       | What to do                                                                                                                                                                                                                       |
| -------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| "Diagram not found, or not accessible with this token."              | The board does not exist, or is outside what the connection covers (allowlist, role cap, no access for the user). Reads and writes answer the same on purpose | Check the id or link. Try `diagram_search`. If it is the user's board, the connection may cover other boards only: explain reconnecting with the board ticked                                                                    |
| "This token's role does not permit that action."                     | Connection is Viewer or Commenter, or not an editor for this board                                                                                            | Say it is read-only. Reconnect: claude.ai Settings, Connectors, Ontographia Lab, Disconnect, add again; on the consent screen choose Editor and tick the boards (admins: "All boards I can edit"). Reading still works meanwhile |
| `REVISION_CONFLICT` (with `currentRevision`)                         | Board changed since you read it. Nothing written                                                                                                              | Re-read (`board_read_region` / `diagram_get`), re-plan, retry once with the new revision. Never blindly overwrite                                                                                                                |
| `RATE_LIMITED` (`retryAfterSeconds`)                                 | About 30 writes per minute per connection                                                                                                                     | Wait the given time, then send one consolidated call                                                                                                                                                                             |
| `INVALID_OPS` / `INVALID_STRUCTURE`, "Not applied (nothing changed)" | Input invalid, or it touches locked elements. Errors list op index or ids                                                                                     | Fix what the message names. For locked ids, ask the user to unlock or leave them out                                                                                                                                             |
| `warnings` on a success                                              | Partial effect: locked elements skipped by `layout_apply`, a frame grown, duplicate edges ignored                                                             | Relay them to the user                                                                                                                                                                                                           |
| `truncated: true`, or `next` / `nextCursor`                          | Output capped at about 120 KB, or more pages                                                                                                                  | Narrow (`frameId`, `elementIds`, `bbox`, `detail: "structure"`) or page with `cursor` (same focus). A cursor from an older revision is refused: start over                                                                       |
| Link "names no focus"                                                | A plain board URL, not a "Copy link for Claude" link                                                                                                          | Ask the user to right-click a selection, frame or canvas and choose "Copy link for Claude", or use `id` plus `frameId` / `bbox`                                                                                                  |
| Link points to a different diagram than `id`                         | Mismatch                                                                                                                                                      | Pass only the link                                                                                                                                                                                                               |
| `diagram_show` shows nothing                                         | Host has no MCP Apps support                                                                                                                                  | Use the "Open in lab" link in the text result; use `diagram_get` outline for your own view. Boards over 600 elements say "too large": narrow the focus                                                                           |
| Tool errors, 401, connector error                                    | Connection expired or was disconnected (Connected apps in the lab, password reset), or the lab's OAuth is off                                                 | Ask the user to reconnect the connector (Settings, Connectors). If sign-in itself fails, their lab administrator must check the OAuth setup                                                                                      |
| User's open tab does not show the change                             | Updates arrive within a few seconds; older tabs may show a conflict on save                                                                                   | Ask them to reload; the change is in History                                                                                                                                                                                     |

Undo: you cannot restore versions. Point the user to History in the editor ("Before AI change" version, or "Review agent change", then restore).
